# アクセシビリティを確認する

- [ ] キーボードだけで主要操作を最後まで行う。Tab の順序と、今どこにいるかが目で分かるかを確認する。[E4-05](../references/e-accessibility.md#e4-05)・[E4-06](../references/e-accessibility.md#e4-06)
- [ ] 縦に読む画面を幅320 CSS px相当で開き、情報と操作が残るか確認する。横に読む画面は高さ256 CSS px相当で調べる。地図のように二次元配置が必要な部分は区別する。[E-02](../references/e-accessibility.md#e-02)
- [ ] ダイアログを開いて背景が操作できないことを確認する。長い説明がある場合は最初に何を読み上げるか、閉じたときは次の操作に合う場所に戻るかも試す。[E2-04](../references/e-accessibility.md#e2-04)・[E2-05](../references/e-accessibility.md#e2-05)・[E2-06](../references/e-accessibility.md#e2-06)
- [ ] 画像は使われ方に合わせて確認する。操作用画像なら操作の結果が分かる名前を付け、横に同じ説明文がある場合は読み上げの重複を確かめる。[E7-01](../references/e-accessibility.md#e7-01)・[E7-12](../references/e-accessibility.md#e7-12)
- [ ] ログインや申込手続きを通して試す。同じ情報をもう一度求める画面や記憶・識別の課題に出会ったら、再利用できる値、代替手段、適用される例外を調べる。[E-09](../references/e-accessibility.md#e-09)・[E-10](../references/e-accessibility.md#e-10)
- [ ] 自動評価で指摘された要素を実際に操作する。評価に使ったツール・対象の画面・確認できた操作を記録し、数値の対象範囲を明確にする。[K13-01](../references/k-studies.md#k13-01)・[K14-01](../references/k-studies.md#k14-01)
