# 動きと停止操作を確認する

- [ ] 端末の「視差効果を減らす」などの設定を切り替える。動きがなくても処理の完了や状態変化が読み取れるか調べる。[E3-08](../references/e-accessibility.md#e3-08)
- [ ] 自動で始まり、他の内容と並んで5秒を超えて続く動き・点滅・スクロールには、一時停止・停止・非表示の手段を用意する。動きが活動に不可欠な場合は適用条件を原文で確認する。[E6-03](../references/e-accessibility.md#e6-03)
- [ ] 強い明滅を使う箇所で、任意の1秒間の回数を確認する。3回を超える場合は、一般フラッシュと赤色フラッシュの両方について規格の閾値を調べる。[E6-02](../references/e-accessibility.md#e6-02)
- [ ] 自動送り中のカルーセルにフォーカスを移す。停止した後、利用者が開始を指定するまで表示が勝手に進まないことを確認する。[E8-05](../references/e-accessibility.md#e8-05)・[カルーセルの例](../templates/carousel.html)
- [ ] アニメーションの途中で画面を閉じる、別の操作を始める、連打する場合を試す。待機中の処理がキャンセルされても画面に古い状態を残さない。[H5-06](../references/h-graphics.md#h5-06)・[H5-11](../references/h-graphics.md#h5-11)
