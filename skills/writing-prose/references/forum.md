# コミュニティのフォーラム告知、メンバーへの個別の PM・DM、運営内の合意形成の投稿

wiki型コミュニティサイトのフォーラムで利用者に出す告知（敬体）と、その文面を運営チャットで合意に回す投稿の書き方。

---

## 告知の本文（利用者向け・敬体）

### 骨格

```
<役職>の <ユーザーメンション記法で自分> です。

本日より、<何を> <どこから> <どこへ> 移行します。

**変わること:**
* <利用者がすること・できること>
  * <条件・補足>
* <利用者から見た結果>

**変わらないこと:**
* <据え置く規則>
  * <困ったときの連絡先>

<既存データの扱いを、投稿時点で済んだ状態として1文>
<問い合わせ先>
```

### 書き方

- **箇条書きの親は1文で言い切り、句点を付けない**。条件・補足・例外は子項目に分ける。1項目に2文を詰めない
- **改まった定着語で書く**: 「移行します」「〜となります」「〜に伴い」「実行できます」「ご自身で実施することができます」「運用は終了となります」。口語寄りの「移します」「要らなくなります」「行えます」は告知では使わない
- **変化は利用者から見た結果の語で書く**: 仕組みの説明（「一覧から外れます」）でなく、利用者に見える結果（「自動で削除されます」）にする
- **利用者の行動が変わらない細部は書かない**: 自動で入力される項目、内部の判定方法など
- **同じ対処先を持つ制約は1項目にまとめ**、対処（「必要があればスタッフへ相談してください」）を子項目に1回だけ置く
- **時点は投稿日を基準にする**: 「本日より」「すべて引き継がれています」と、投稿した時点で済んでいる状態として書く。日付のプレースホルダや「移行時に引き継ぎます」のような予定形は、予告として別に出す場合だけ使う

### 終了・クローズの投稿

```
<役職>の <ユーザーメンション記法で自分> です。

<変更>に伴い、このスレッドでの<受付>を終了します。

今後、<代わりの手段> からご自身で実施することができます。
詳しくは [<告知のURL> 告知スレッド] をご覧ください。
```

- 理由は「〜に伴い」の一句にまとめる。日付や経緯は書かない
- 儀礼的な謝辞（「これまでご利用いただき、ありがとうございました」）で締めない

## 個別の PM・DM（運営の名義で、メンバーに依頼・連絡する）

権利の移譲・作品の修正・手続きの案内など、運営の名義で1人のメンバーに送る文面。相手は運営を組織として読むので、告知と同じく改まった書き言葉で書き、依頼は相手が断れる形にする。

### 骨格

```
<宛名>さん

<組織名>サイトスタッフです。
<相手に関わる対象>について、<依頼の要旨>をお願いしたく、ご連絡いたしました。

<背景を1〜2文。「〜を進めております」「〜いたします」>

**対象のページ**
<一覧>

**ご対応のお願い**
<条件>いただける場合は、<依頼の内容>いただけますと幸いです。
<こちらが行う作業>は、スタッフにて実施いたします。

<相手がそのまま使う文面があればコードブロック>

<断る場合の案内>は、お手数ですが<連絡手段>にてお知らせくださいますよう、お願いいたします。
```

### 書き方

- 自分側の動作は「〜いたします」「〜にて実施いたします」「〜を進めております」で書く。「〜します」「〜が担当します」で止めない
- 依頼は「〜いただけますと幸いです」「ご〜いただけますと幸いです」の言い切りで書く。「〜してください」は命令に、問いの形（「〜いただけますでしょうか」）は硬すぎて読み手に違和感を与える
- 相手が応じるかどうかを決める依頼（権利の移譲・同意）は、「<条件>いただける場合は」と条件を前に置く。応じない選択肢の案内も末尾に置く
- 動作をつなぐときは「〜のうえ」「〜いただいたうえで」を使い、「〜して」「〜していただき」と開かない。例示は「〜等」と書く
- 先に送った連絡の訂正・追送は、漏れを事実で1文（「〜において、以下の<対象>の記載が漏れておりました」）にし、背景は繰り返さない

## 運営チャットでの合意形成の投稿

成果物と、これから行う作業と、出す文面を1つの投稿にまとめ、リアクションで合意を取る。

```
<成果物の名前>
<URL>

<成果物の名前>
<URL>

--------

<ページ名> 改定案
<URL>

--------

上記<何>を<どうし>、<何>を編集します
その後、以下文面で<告知の場所>を立てます

（コードブロック: 1行目に `Subject: <題>`、空行、本文）

--------

また、<別の場所>は以下文面で<どうし>ます

（コードブロック: 本文）
```

- 成果物は「名前1行＋URL1行」を空行で区切って並べ、まとまりごとに `--------` で区切る
- 作業の宣言は「〜し、〜します」「その後、〜します」の短文で、句点を付けない
- 文面はコードブロックに入れ、題は本文と分けて `Subject:` 行に書く
