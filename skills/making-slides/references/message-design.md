# 主張の設計

目次: 1 読み手の3問 / 2 主張の階層 / 3 見出し / 4 証拠の強さ / 5 設計表 / 6 ページの原則 / 7 既存デッキの点検 / 8 載せないもの

## 1. 読み手の3問

読み手が資料を閉じたときに答えられるべき問いを3つ書く。型ごとの例は `references/deck-types.md`。

- 各問いに、答えるページを1つ決める。答えが複数のページに散るなら構成を見直す
- 問いは読み手の立場で書く（「承認してよいか」）。書き手の作業（「何をやったか」）を問いにしない

## 2. 主張の階層

```
資料全体の主張（1文）
└ 章の主張（章ごとに1文）
   └ ページの主張（＝見出し。1行）
      └ 本文（図・表・箇条書き）は主張の根拠
```

- 資料全体の主張は2要素までに絞る（「置き換えられた」と「範囲が広がった」のように）
- 主張を書けないページは作らない。統合するか削除する
- 数字は主張の根拠としてページに置く。数字だけを並べて意味づけを読み手に任せない

## 3. 見出し

- ページの見出しを主張の文にする（assertion-evidence）。「検証結果」ではなく「キャッシュを分けると応答が3割速くなった」と書き、下に根拠を置く。見出しを文にしたデッキで、聴衆の理解と記憶が上がった報告がある（Alley）
- 根拠は図・表・写真・コード・数値のどれかを主にし、箇条書きは補助にする。ただし全ページに図を置く必要は無い（Farkas の反論。採否は `references/sources.md`）
- 見出しは1行に収める。2行になるなら修飾を削り、主張は残す
- 例外: 表紙・目次・章扉・付録の見出しは、何のページかが分かる名詞句でよい

## 4. 証拠の強さ

数値と事実を、確かさの違いで分けて置く。混ぜると、読み手は「この数字はどこまで確かか」を判断できない。

- 実測・人が確認した結果
  - 例: 本番の計測値、人手で照合した結果
  - 置き方: 結論と判定の根拠のページ
- 機械の出力だけ
  - 例: 人が確認していない大量の判定
  - 置き方: 別のページか、列見出しで種別を示す
- 相手が記入・提供した値
  - 例: 先方の評価表、顧客の資料の数値
  - 置き方: 出典を書いて引用する
- 書き手の見立て・試算
  - 例: 分類、効果の試算
  - 置き方: 前提と仮定の値を注記に書く

- 試算は「件数は事実、1件あたりの値は仮定」のように、事実と仮定を分けて式で示す
- 前提の違う試算を合計しない

## 5. 設計表

本文を書く前に、次の表を作業ディレクトリの Markdown に書き、ユーザーの確認を取る。

1. 型・読み手・成果物の形式・持ち時間（`references/deck-types.md`）
2. 読み手の3問と、答えるページ
3. 資料全体の主張1文と、それを支える事実3つ（事実・出所・証拠の種別）
4. ページの表: `# | 見出し（主張） | 根拠（図・表・数値） | 証拠の種別 | 出所`
5. 2版を作るときは、版ごとに変えるページ
6. 載せないもの（§8 に当たると決めたもの）

再作成のときは、ページの表に「現行からの変更」の列を追加する。

## 6. ページの原則

- 1ページ1主張。役割の違う内容（判定と経緯など）を1ページに詰めない
- 同じ論点は1ページにだけ置く。ほかのページからは参照する
- 依頼は本文に書かず状態を書く（相手に頼むことは送付の文面に書く）。会議の投影の「決めてほしいこと」と、中間報告の「残りの期間でしてほしいこと」は、それ自体が主張なので本文に書く
- 前置き（進め方・体制・期間）は主役のページの下段に圧縮する。主役のページと同じ重さにしない
- 目次ページは、章が多く読み手が途中のページを探す資料（読む資料・長い報告）のときだけ置く（目次は主張に届くまでのページを増やすため）。それ以外は章を各ページの章番号で示す

## 7. 既存デッキの点検

再作成の前に、1ページずつ問題を書き、横断する問題を数で示す。指摘された1文だけを修正すると、同じ構造の問題が別のページに残る。

- 見出しが主張になっていない
  - 数え方: ページ数
- 1ページが複数の役割を持つ
  - 数え方: ページと役割の数
- 同じ論点が複数のページに散る
  - 数え方: 論点ごとの出現ページ数
- 依頼形・「確認中」が本文にある
  - 数え方: 箇所数
- 型に合わない密度（投影で文章、読む資料で語だけ）
  - 数え方: ページ数
- 下半分が空いた主役のページ
  - 数え方: ページ数
- 読めない大きさの注記・凡例
  - 数え方: ページ数
- 単位の違う値の合計
  - 数え方: 箇所数

数を示したら、§2〜§6 の原則で構成を決め直し、設計表に進む。

## 8. 載せないもの

- 意味づけできない数字（作業の総量、件数だけの集計）
- 評価語だけの文（「大きく改善」）。比べた2つの値で書く
- 1件の例から全体を述べる文
- 防御的な注記（「〜は記録から分からないため含めていません」）と運用の説明（「随時更新します」）
- 相手を批判する引用、出所の無い効果の数値
