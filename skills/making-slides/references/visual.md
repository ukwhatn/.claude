# 見た目の規則

目次: 1 文字の大きさ / 2 色とコントラスト / 3 書体 / 4 ページの構成 / 5 図表と画像 / 6 動き / 7 AI らしい兆候

PJ・組織のテーマに規定があれば、そちらを優先する。本ファイルは規定の無い論点の既定値。

## 1. 文字の大きさ

- 投影の本文は 24pt 以上、下限 18pt（`references/sources.md` の出典で 16〜24pt に割れるので、遠い席を想定して 24pt を既定にする）
- 1280×720px のスライドを 13.33 インチ幅として扱うと、1pt ≒ 1.33px。24pt は 32px、18pt は 24px にあたる
- 読む資料（PDF）は画面と印刷で読む前提で、本文を投影より小さくしてよい。それでも注記・出典を 1280px 幅で 16px 未満にしない
- 1ページに収めるために文字を下限より小さくしない。内容を削るかページを分ける
- 見出し・本文・注記の3段階を基本にし、ページごとに大きさを変えない（テーマで固定する）

## 2. 色とコントラスト

- 文字と背景のコントラストは 4.5:1 以上（大きい文字は 3:1 以上）。投影機は暗い色が浮くので、薄いグレーの本文と、写真の上の文字を避ける
- 色だけで意味を示さない（判定・系列には文字・形・位置も添える）
- 強調の色は1つにし、主張を支える数値か選択だけに使う。背景・枠・見出しを全ページ色で塗らない
- グラフの配色は `/dataviz` に従う
- 会場の明るさが分からないときは、明るい背景を既定にする（暗い背景は明るい会場で読みにくい）

## 3. 書体

- 既定は `Noto Sans JP` の固定ウェイト（400・700）で、テンプレートが npm の `@fontsource/noto-sans-jp` を node_modules から読む。システムの和文書体（ヒラギノは CFF 形式）・可変フォント・疑似太字は、Chrome の PDF で Type3 になって書体名が消える。CDN の Web フォントは、オフラインの会場とビルドで別の書体に置き換わる
- 別の書体を使うときも、固定ウェイトの書体ファイルを node_modules かデッキのディレクトリから読み、PDF に書体名つきで埋め込まれるかを `scripts/verify_pdf.py` の書体の一覧で確認する（Type3 と出たら別の配布形式を試す）
- 書体は2つまで（見出しと本文、または和文と欧文）。数字とコードは等幅にする
- 和文と欧文の組み合わせ、題材に合わせた書体の選定は `/anything-frontend-art-direction` の「和文と欧文を合わせる」と書体の事例データを使う。CSS で指定した名前ではなく、PDF に埋め込まれた書体名で確認する（`scripts/verify_pdf.py` が一覧を出力する）
- 行間はテーマで固定し、ページごとに詰めない。和文の本文を両端揃えにしない（語の間が不揃いになる）

## 4. ページの構成

- 1ページの要素（見出し・図・表・箇条書きのまとまり）が増えたら、そのページが複数の役割を持っていないか見直す
- 投影の箇条書きは1階層を基本にし、遠い席から読める大きさ（§1）で収まる項目数に絞る
- 余白はページの端と要素の間で統一する。要素を端まで詰めない
- ページ番号を全ページに付ける（質疑と議事で「何ページ目」と指せるように）。表紙は除いてよい
- 毎ページのロゴ・会社名・著作権表記は、テーマが決めているときだけ置く

## 5. 図表と画像

- 図表には見出しの主張を支える部分だけを残す。読み取ってほしい値を強調し、ほかは目立たせない
- 表は、比べる対象と属性が3つ以上あるときに使う。セルに文が入るなら箇条書きにする
- 画像は投影の解像度（1280px 幅以上）で用意し、出典とライセンスを確認する。生成画像を使うときは、課金や外部への送信があるならユーザーに確認する
- スクリーンショットは読ませたい部分を切り出して拡大する

## 6. 動き

- 動きは、状態の変化・順序・因果・同じものの移動を見せるときだけ使う。ページの装飾として動かさない
- 動きだけで情報を伝えない。最終状態のページだけで主張が分かるようにする（PDF・印刷・録画で動きが見えないため）
- `prefers-reduced-motion` が有効なときは、移動・拡大の動きを切り替えの無い表示にする（テンプレートで対応済み）
- 1秒に3回を超えて点滅させない（WCAG 2.3.1）
- 同じ種類の変化には同じ動きを使う。ページごとに遷移の種類を変えない

## 7. AI らしい兆候

次は、作り込んだように見せる装飾で、主張を支えない。見つけたら外す。HTML のデッキは `/unslop` の兆候の一覧で点検する。

- 色相をまたぐグラデーションの背景・文字、光彩、色の付いた影
- 見出しや箇条書きの頭の絵文字
- すべてのページを同じ形のカード3つで構成する型
- 「ポイント」「まとめ」のような中身を言わないラベルの見出し
- 中身の無い大きな数字の装飾（意味づけの無い「10x」）
