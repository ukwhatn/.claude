# 用字用語と操作の語彙

PJに用語表があればそちらが優先する。ここは規定が無いときの既定値。

## 目次

- 操作を表す語

## 操作を表す語

1つの操作に1つの語を決め、ボタン・見出し・通知・エラーで同じ語を使う。

| 操作 | 使う語 | 使わない語 | 補足 |
|---|---|---|---|
| 新しく作る | 追加 | （混在させない）登録・作成・新規 | 「登録」「作成」が明らかに合う対象（パスワードを登録、書類を作成）ではその語でよい。PJで対象ごとに固定する |
| 既存のものを変える | 編集（画面を開く）／保存（確定する） | 更新・変更の混在 | 「更新」は画面の再読み込みと紛れる |
| 同じものをもう1つ作る | 複製 | コピー | 「コピー」は貼り付けを伴う操作（クリップボード）にだけ使う |
| 外のデータを入れる | 取り込む | インポート | |
| データを外に出す | 書き出す | エクスポート・出力 | ファイルをそのまま受け取るのは「ダウンロード」 |
| 元と同じ状態にする | 同期 | 取得 | |
| 画面を最新にする | 再読み込み | 更新・リロード・再読込 | 「画面を再読み込みしてください」 |
| ボタンを操作する | 押す | クリック・タップ | 端末を問わない語にする |
| リンクを操作する | 開く | クリック・タップ | |
| 画面を移る | 移動 | 遷移 | |
| 順序を変える | 並べ替え | 並び替え・ソート | |
| 条件で減らす | 絞り込み | フィルター・フィルタリングの混在 | PJが「フィルター」で統一済みなら従う |
| 切り替え式の設定 | 有効にする／無効にする | オン・オフとの混在 | |
| チェックボックス | チェックを入れる／外す | 選択する | |

## 止める・戻すの使い分け

| 語 | 意味 |
|---|---|
| キャンセル | まだ実行していない操作をやめる（ダイアログを閉じる、編集をやめる） |
| 取り消し | 実行済みの操作を無かったことにする（申請を取り消す） |
| 中断 | 実行中の操作を止める |
| 解除 | 設定・状態を元に戻す（連携を解除、固定を解除） |
| 差し戻し | 承認を求められた側が、修正を求めて返す |
| 戻す | 工程の中で前の状態に戻す（未対応に戻す） |

## 状態を表すラベル

| 段階 | 型 | 例 |
|---|---|---|
| 始まる前 | ◯◯前・未◯◯ | 開始前・未送信・未対応 |
| 途中 | ◯◯中・◯◯待ち | 対応中・承認待ち |
| 終わった | ◯◯済み・完了 | 送信済み・完了 |
| 打ち切り | 終了・◯◯終了 | 受付終了 |
| 問題あり | 要◯◯・差し戻し | 要確認 |

「◯◯待ち」は、誰か（システム・他の人）の次の操作を待っている状態にだけ使う。

## 表記（数字・記号・空白・括弧）

| 項目 | 書き方 | 例 |
|---|---|---|
| 数字 | 半角の算用数字。熟語・慣用句は漢数字 | 3件、1つ、一覧、一時的 |
| 桁区切り | 3桁ごとに半角カンマ | 1,000件 |
| 期間の単位 | 「か月」「か所」 | 3か月 |
| 範囲 | 「〜」 | 1〜10件 |
| 時刻 | `hh:mm`（秒が要るときだけ `hh:mm:ss`） | 09:30 |
| 単位記号 | 半角で、数字との間を空けない | 5MB、50% |
| 英数字と日本語の間 | 空白を入れない | PDFファイル、2件の案件 |
| 句読点 | 「、」「。」 | |
| 疑問符・感嘆符 | 全角。後に文が続くときは全角の空白を1つ | 削除しますか？　この操作は… |
| コロン | 全角。前後を空けない | 例：name@example.com |
| 省略 | 三点リーダー「…」を1つ | 読み込み中… |
| 列挙 | 順序に意味があれば「、」、無ければ「・」 | |
| 階層の区切り | 半角の `/` `>` | 設定 > 通知 |

括弧:

| 記号 | 用途 |
|---|---|
| （ ） | 補足 |
| 「 」 | 画面上のメッセージ、ファイル名、ユーザーが入力した値 |
| ［ ］ | 文中でボタン名・タブ名・設定項目名を指すとき |
| 【 】 | ユーザーが名付けたものの名前を文中で指すとき |
| { } | 変数（半角。テンプレートの中だけ） |

句点:

- 見出し・ボタン・ラベル・状態のラベル・表の中の単語には付けない
- 説明・エラー・通知の文には付ける。1文だけでも付ける
- 箇条書きは、単語なら付けず、文なら付ける

## カタカナ語

| 語尾 | 長音 | 例 |
|---|---|---|
| -er・-or・-ar | 付ける | ユーザー、サーバー、フィルター、メンバー、エディター |
| -y | 付けない | カテゴリ、セキュリティ、メモリ |
| 例外 | 付けない | ブラウザ、フォルダ |

- 「ウィ・ウェ・ウォ」を使う（ウィンドウ、ソフトウェア）
- 略さない（スマートフォン、パソコン、アプリケーションは「アプリ」が定着しているのでアプリでよい）
- カタカナ語は、漢字語・和語で通じるならそちらを使う（フリーテキスト→自由記述、プレーンテキスト→装飾なしの文字、リクエストする→依頼する／受け付ける）。利用者に定着した語（ログイン、パスワード、メール）は言い換えない

## 漢字とひらがな

- 補助動詞・形式名詞・接続詞はひらがな（〜してください、〜できます、こと、とき、ため、および、また）
- 「下さい」「出来る」「致します」「頂く」は使わず、ひらがなにする
- 「すべて」「あらかじめ」「もとに」はひらがな。「元に戻す」は漢字
- 送り仮名は省かない（取り消し、書き込み、読み込み、受け付け）

## 文型の早見

| 場面 | 文型 |
|---|---|
| 完了 | {対象}を{操作}しました |
| 後で処理される | {処理}を受け付けました |
| 失敗（原因が分かる） | {操作}できませんでした。{原因}。{対処}してください。 |
| 失敗（原因が分からない） | {操作}できませんでした。時間をおいて、やり直してください。 |
| 仕様として不可 | {状態}の{対象}は{操作}できません |
| 上限 | {対象}は{上限}までしか{操作}できません |
| 権限が無い | この操作に必要な権限がありません。{誰に何を頼むか}。 |
| 入力の条件 | {条件}で入力してください |
| 削除の確認 | 「{名前}」を削除しますか？　この操作は元に戻せません。 |
| 空（データなし） | {対象}はありません |
| 空（条件に一致なし） | 条件に合う{対象}はありません |
| 読み込み中 | 読み込み中… |
| 読み込み失敗 | {対象}を読み込めませんでした。画面を再読み込みしてください。 |
