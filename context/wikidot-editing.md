# Wikidot のページを保存・編集するとき

Read when: Wikidot のページを作成・保存・編集する前（本番・下書き・検証用ページ・モックのどれでも。スクリプト経由も含む）。

- 編集コメント（編集履歴に残る「変更の要約」。wikidot.py の `comment` 引数、編集画面の要約欄）は空にする。ユーザーが文面を指定したときだけ入れる
- ソースを空文字列にする保存は反映されず、元のソースが残る。空にするときは空白1文字で保存し、保存後にソースを読み直して確かめる
- `[[code]]` を保存した後の配信は、`local--code_/<ページ>/<n>` かクエリを付けた URL で確かめる。`local--code/<ページ>/<n>`（`<ページ>/code/<n>` の転送先）は保存後の数分間、古い版を返すので、それを見て修正が効いていないと判断しない
