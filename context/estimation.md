# 工数見積・スケジュール回答

Read when: 工数・所要期間・スケジュールの見積を求められたとき（計画書・PR 分割に見積を書く場合を含む）。

人間が手で実装する前提の人日見積を出さない（学習データ由来のデフォルトであり、Claude Code 実装の実態と乖離する）。次の形で出す:

- **実装量はセッション数・PR 数で見積もる**（Claude Code の実行単位に対応させる。人日換算しない）
- **人間の関与が必要な工程は分離して人時で出す**（レビュー・受け入れ確認・意思決定・対外調整）
- **カレンダー時間はレビュー往復回数・CI・承認待ちを律速として見積もる**（実装速度からの機械的な割り算はしない）
- 人間実装前提の数字が必要な文脈（対外見積等）では、Claude Code 実装前提と人間実装前提を分けて併記する
